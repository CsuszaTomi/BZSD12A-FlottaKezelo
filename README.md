# Flotta- és Eszköznyilvántartó Rendszer (Céges Belső Eszköz)

## 📝 Projekt Koncepció

Ez a projekt egy átfogó céges belső rendszer, amelynek célja a vállalat tulajdonában lévő vagyontárgyak (autópark, laptopok, szerszámok és egyéb eszközök) hatékony kezelése. A szoftver megkönnyíti az eszközök kölcsönzésének, kiadásának nyomon követését, valamint a kötelező és eseti karbantartások adminisztrációját.

## ⚙️ Tervezett Fő Funkciók

* **Eszközök Nyilvántartása:** Új eszközök (autók, IT eszközök, szerszámok) rögzítése, kategóriákba sorolása és adataik kezelése.
* **Kölcsönzés és Kiadás:** Eszközök hozzárendelése munkatársakhoz, átvételi és leadási határidők naplózása.
* **Karbantartás Kezelés:** Szervizigények, kötelező vizsgálatok és javítások ütemezése, valamint visszamenőleges nyilvántartása.
* **Állapotkövetés:** Valós idejű áttekintés arról, hogy egy adott eszköz éppen hol van, ki használja, vagy szervizben van-e.
* **Jogosultságkezelés:** Különböző felhasználói szerepkörök (pl. Adminisztrátor, Raktáros/Flottakezelő, Átlagos munkatárs).
